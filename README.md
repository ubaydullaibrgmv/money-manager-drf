# 💰 Money Manager API (DRF)

Ushbu loyiha shaxsiy moliyaviy oqimlarni boshqarish uchun mo'ljallangan professional **RESTful API** hisoblanadi. 

## ✨ Imkoniyatlar
* **🔐 Autentifikatsiya:** SimpleJWT orqali (Telefon raqami bilan).
* **💳 Hamyonlar:** Ko'p valyutali hamyonlar (UZS, USD, EUR).
* **💸 Tranzaksiyalar:** Avtomatik balans hisob-kitobi.
* **🏗 BaseModel:** `created_at` va `updated_at` maydonlari bilan professional arxitektura.
* **📂 Dokumentatsiya:** Swagger UI (/api/docs/).

## 🛠 Texnologiyalar
* Django REST Framework
* PostgreSQL
* SimpleJWT
